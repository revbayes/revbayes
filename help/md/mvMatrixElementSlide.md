## details
`row` and `col` confine the move to one line of the matrix, counting from 1; 0, the default, draws from every element. Giving both pins a single element. This is for a matrix whose margins hold different quantities: the birth-death matrix of `dnFBDRP` has one row per taxon and holds births in column 1 and deaths in column 2, so `col=1` sliding only the birth times.
