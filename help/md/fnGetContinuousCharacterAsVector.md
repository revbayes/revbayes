## name
fnGetContinuousCharacterAsVector
## title
Discretize a Gamma distribution
## description
`fnGetContinuousCharacterAsVector` returns the continuous character of your choice from a character matrix as a vector. The elements inside the vector is ordered alphabetically by the species name.
